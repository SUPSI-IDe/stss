# Pixel_urbani

## Description

This folder contains the materials developed for the **Data Mapping** activity conducted during **Pixel Urbani**, a public engagement program organized within the **LongLake Festival Lugano**, promoted by the **City of Lugano**, and held at **Studio Foce** on **16–17 July 2025**.

The activity explored data mapping as a collective practice for documenting everyday urban experiences. Citizens were invited to reconstruct their waste-disposal routines by tracing routes across the city and annotating printed maps with contextual information such as household characteristics, disposal frequency, timing, means of transport, and related daily activities.

Using stickers, strings, pins, and handwritten notes, participants transformed personal observations into visual traces that could be shared, compared, and discussed. Through this process, individual experiences were connected to broader urban patterns, making visible how waste-related practices are distributed and experienced across the city.

## Folder Contents

### `households_stickers`

Vinyl-cut sticker templates produced using a vinyl cutting machine.

The stickers were used by participants to represent the number of household members (using stickers with different shapes).

### `Time-ruler.ai`

Vector file for laser-cutting a series of **time rulers**.

The rulers were designed as physical annotation tools that enabled participants to record and visualize time vertically on printed maps, making temporal patterns and sequences easier to identify and compare.

### `Pixel_urbani_probes.csv`

Dataset describing the mapping probes and annotation system used during the Data Mapping activity.

The file documents the different types of information collected from participants, the interaction modalities through which data were recorded, the encoding systems used to represent observations on the maps, and the related physical materials employed during the activity.

The dataset is organized according to the following fields:

| Field | Description |
|---------|-------------|
| **Collected data** | Type of information collected from participants. |
| **Interaction modality** | Instructions describing how participants recorded or represented the information. |
| **Values / Encoding** | Visual or material coding system used to represent the collected data. |
| **Correlated file** | Associated physical template or fabrication file used during the activity. |

The probes captured both quantitative and qualitative aspects of waste-disposal practices, including:

- Household size
- Transport mode used to reach waste-collection points
- Distance travelled for waste disposal
- Time of disposal
- Type and frequency of waste disposal
- Related activities, habits, and observations
- Neighbourhood of residence

The file also specifies how each variable was translated into visual elements such as stickers, strings, pins, colours, and written annotations, enabling participants to collectively construct and compare spatial representations of their everyday waste-management routines.
