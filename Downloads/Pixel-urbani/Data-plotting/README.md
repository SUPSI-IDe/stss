# Data-Plotting

## Description

This folder contains the materials developed for the **Data Plotting** activity conducted during **Pixel Urbani**, a public engagement program organized within the **LongLake Festival Lugano**, promoted by the **City of Lugano**, and held at **Studio Foce** on **16–17 July 2025**.

The activity explored data plotting as a collective practice for visualizing and interpreting urban data generated through the Data Walking activities. Rather than presenting data as fixed representations, participants were invited to explore different visualizations and discuss how images, sensor readings, and spatial information could reveal different aspects of urban phenomena.

Through collective observation and discussion, citizens connected individual experiences to broader urban patterns, using data visualizations as tools for reflection, interpretation, and dialogue.

## Folder Contents

### `index.html`

Main file used to launch the **Data Exploration Interface** locally in a web browser.

The interface allows users to browse, visualize, and compare datasets generated through the DIY Urban Scraping activities using multiple visualization modes, including grid views, timelines, scatterplots, and maps.  [oai_citation:0‡script.js](sediment://file_00000000853871f49c228b89f2c5c4a5)

### `assets/`

Folder containing all visual assets and datasets used by the interface.

#### `assets/archive/`

Archive containing the datasets generated through the DIY Urban Scraping activities.

##### `_output_04`

Dataset generated by **Entro-py**.

Contains:

- Images collected during the activity

- `gps_log.csv` containing timestamps and geographic coordinates associated with the observations

##### `_output_05`

Dataset generated by **Thermal-access**.

Contains:

- Thermally processed images

- `metadata.json` containing temperature measurements and related metadata

##### `_output_06`

Dataset generated by **Urban-overflow**.

Contains:

- Processed images

- `metadata.json` containing waste-overflow measurements, including:

  - overflow ratio

  - estimated waste area

  - average container area

##### `_output_07`

Additional dataset generated by **Urban-overflow** with the same structure as `_output_06`.

Contains:

- Processed images

- `metadata.json`

##### `_output_08`

Dataset generated by **Thermal-access**.

Contains:

- Thermally processed images

- `metadata.json` containing thermal measurements including minimum, maximum, and average recorded temperatures for each image.  [oai_citation:1‡metadata.json](sediment://file_00000000d2ac71f4b1acc7243a574957)

##### `_output_09`

Dataset generated by **Entro-py**.

Contains:

- Images collected during the activity

- `gps_log.csv` containing timestamps and geographic coordinates associated with the observations

### `scripts/`

Folder containing the JavaScript files used by the Data Exploration Interface.

#### `script.js`
Main application script responsible for:


- Loading and managing datasets from the archive folders

- Displaying image collections and associated metadata

- Switching between different visualization modes

- Rendering interactive views using p5.js

- Enabling image inspection and metadata exploration

- Supporting comparative analysis of datasets generated by different DIY Urban Scraping tools


The interface provides four visualization modes:
- **Grid** — displays all collected images as a visual archive

- **Timeline** — arranges observations according to their timestamps

- **Scatterplot** — plots images according to sensor values and temporal information

- **Map** — positions observations according to their geographic coordinates when available

#### `utilities.js`

Collection of helper functions used throughout the interface.

These functions support:
- Timestamp parsing and conversion

- Metadata processing

- Coordinate transformations

- Data normalization

- Utility operations required by the visualization system

#### `p5.min.js`

Local copy of the **p5.js** JavaScript library used to render the interactive visualizations, manage graphical elements, and support user interaction within the browser.

### `style.css`

Stylesheet controlling the visual appearance of the interface, including:

- Page layout

- Typography

- Interface components

- Dataset selectors

- Visualization containers

- Responsive display behaviour
