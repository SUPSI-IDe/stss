#Gesture-Tracking

## Description

This folder contains the materials developed for the **Gesture Tracking** activity conducted during **Pixel Urbani**, a public engagement program organized within the **LongLake Festival Lugano**, promoted by the **City of Lugano**, and held at **Studio Foce** on **16–17 July 2025**.

The activity explored gesture tracking as a participatory method for documenting waste-disposal practices through bodily movement. Citizens were invited to select a waste category and a disposal facility type through a digital interface, then perform a simulated waste-disposal gesture using a physical probe representing their selection. Their movements were captured in real time through a motion-tracking installation and recorded as video sequences.Following the recording, participants annotated their gesture through the interface by providing additional contextual information. The resulting archive combines movement recordings and participant-generated descriptions, enabling reflection on how waste infrastructures are physically encountered and experienced. 

## Folder Contents

### `poseAndcounter.toe`

Main TouchDesigner project used during the installation.

The file manages participant interaction, gesture tracking, video recording, real-time visualization, and the archiving of recorded gestures.

### `poseAndcounter.30.toe`

Development and backup version of the main TouchDesigner project.

### `project/`

Folder containing the software infrastructure supporting the Gesture Tracking installation.

The system combines a web-based participant interface, a local server, and the TouchDesigner application to coordinate gesture recording, participant annotations, and data archiving.

#### `public/`

Contains the files required to run the participant interface.

##### `index.html`

Main interface used by participants before and after the gesture-tracking session.

Through the interface, participants could:

- Select a waste category
- Select a disposal facility type
- Start a recording session
- Annotate their recorded gesture after the interaction

##### `app.js`

Main client-side application controlling participant interactions, data entry, communication with the server, and synchronization with the gesture-tracking system.

##### `styles.css`

Stylesheet defining the visual appearance and layout of the participant interface.

#### `server.js`

Node.js server responsible for communication between the participant interface and the TouchDesigner installation.

The server manages recording sessions, participant annotations, data exchange, and the organization of media generated during the activity.

#### `export/`

Folder containing exported recordings and media generated by the installation during participant interactions.

#### `optimized/`

Folder containing processed and optimized media assets used for visualization, archiving, and real-time display within the installation.

#### `package.json`

Project configuration file defining the software dependencies required to run the system.

#### `package-lock.json`

Automatically generated dependency file documenting the software libraries and versions used by the project.

#### `node_modules/`

Folder containing the external JavaScript libraries required to run the web interface and local server.

### `toxes/`

Collection of TouchDesigner components and machine-vision modules used during the development of the Gesture Tracking installation.

The folder contains reusable components supporting real-time body tracking, gesture detection, computer vision, and image analysis.

Key modules include:

- `pose_tracking.tox` — body pose estimation and skeleton tracking
- `hand_tracking.tox` — hand tracking and gesture detection
- `object_tracking.tox` — object recognition and tracking
- `MediaPipe.tox` — integration of Google's MediaPipe framework
- `face_tracking.tox` and `face_detector.tox` — facial detection and tracking
- `image_classification.tox` — image classification utilities
- `image_segmentation.tox` — image segmentation tools
- `image_embeddings.tox` — image feature extraction utilities

These components supported the prototyping and implementation of the gesture-tracking system used to capture and record participants' waste-disposal gestures.

#### `Backup/`

Contains backup versions of TouchDesigner project files created during the development and testing of the installation.
