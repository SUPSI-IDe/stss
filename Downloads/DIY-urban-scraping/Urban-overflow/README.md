# Urban-overflow

## Description

This folder contains the dataset collected with **Urban-overflow**, a DIY urban scraping tool designed and developed by students at SUPSI during the **DIY Urban Scraping Summer Workshop**.

Urban-overflow supports citizen reporting of excessive waste accumulation around urban ecopoints. Using AI-based object recognition, the tool detects garbage overflow outside waste containers and generates images whose color and saturation levels vary according to the type and quantity of waste detected.

The resulting visualizations make visible both the composition and intensity of waste accumulation, supporting reflection on waste management practices and the optimization of collection logistics.

## Data Collection Context

The data were collected in **Lugano (Switzerland)** on **16–17 July 2025** during the **Pixel Urbani** workshop, organized within the **Lugano LongLake Festival**.

Data collection took place through a series of guided urban walks involving citizens and workshop participants in the **Foce–Cassarate area**, where observations of waste accumulation around public collection points were recorded.

## Visualization Scheme

### Waste Categories

| Waste Type | Color |
|------------|--------|
| Undifferentiated Waste | Red |
| Metal | Blue |
| Paper and Cardboard | Yellow |
| Glass | Green |
| Batteries | Black |

### Overflow Intensity

| Saturation Level | Meaning |
|------------------|---------|
| 0% (B&W image) | No trash outside bin |
| 15% saturation | Low overflow |
| 50% saturation | Medium overflow |
| 90% saturation | High overflow |

## Folder Contents

### `Urban-overflow_camera`

Folder containing all images generated by the Urban-overflow tool.

Images are algorithmically modified according to the detected waste category and the estimated level of overflow around collection points.

### `Urban-overflow_metadata.json`

Metadata file containing structured information associated with each observation.

The file may include:

- Image filename
- Timestamp
- Overflow ratio
- Estimated waste area
- Average container area
- Additional sensor and device-generated parameters

Example fields include:

- `image_file`
- `timestamp`
- `ratio`
- `average_bin_area`
- `total_trash_area`
